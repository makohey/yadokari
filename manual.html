ヤドカリってどんな手帳？About

決められた入力から、自分の「好き」を足していける手帳です。使うほど、自分の手帳になっていきます。

① 基本は、最初からそろっています

出勤・休み・外出・買い物・通院など、よく使う種類は初めから入っています。すぐに使えます。

② 自分の項目を足せます

釣り・筋トレ・読書・カフェ・ペット・家庭菜園…。暮らしや趣味に合わせて、自分の種類（🏷️ すること）を足せます。足した言葉が文にあれば、自動でその種類になります。

③ 足した項目ごとに数えられます

今月は出勤が何日、休みが何日、釣りに何回行ったか。自分の傾向を、あとから数字で見られます。

④ 使わなくなったら、外せます

趣味が変わっても大丈夫。使わない種類は隠したり外したりできます。前に入れた予定はそのまま残ります。

⑤ 部品を足して、育てられます

読書カード・ハビットトラッカー・週のメモなど、使いたい部品だけ足せます。足さない部品は読み込まないので、軽いままです。

使い方は自由

決められた使い方だけじゃありません。仕事のシフト、趣味の記録、日記の入口、なんでも。

自分だけの記号で

絵文字は、自分だけが意味を知っている記号として使えます。🍓 や 🌙 に自分で意味を決めれば、人に見られても伝わりにくく、月ごとに数も数えられます。専用の機能を増やさずに、プライベートな記録ができます。

小さな仕掛けも

説明書には書いていない、小さな仕掛けがあります。見つけた人だけの、ちょっとしたラッキーです。

いちばん大事なことThe core

  • 中身は、この端末の中だけにあります。サーバーにもクラウドにも控えはありません。
  • 外へ出るのは、あなたが「送る」「📅」「控えを書き出す」を押した時だけです。自動では何も出ていきません。
  • 日付・時刻・数を数えるのは、毎回コード（決まった計算）がやります。AIは使わなくても全部動きます。
  • 電波がなくても（飛行機モードでも）、一度開いたことがあれば開けます。
消えたら戻せません。ときどき「控えを書き出す」で控えを作っておいてね。大事な予定は、今まで通りの手帳にも残しておくと安心です（試作版です）。

入れるAdd

上の欄に、ふだんの言葉で1行書いて「読み取る」を押します。

明日9時 歯医者10/25 出勤今日 牛乳買う10/24 希望

  • 何行か書くと、1行ずつ読み取ります。
  • 🗓️：カレンダーから日付を選ぶと、書いている行の頭に入ります。日付のない行では、上の行の日付から開きます（続けて入れる時に楽）。
  • 🕘：時刻を選ぶと、日付の後ろに入ります。
  • 絵文字もそのまま使えます。🏥 ☕ のように自分だけの記号にしてもOK。月ごとに数えます。

確認カードCheck

読み取った中身が、カードで出ます。「これで入れる」を押すまでは、何も入りません。

  • まちがっていたら、その場で直してから入れます。
  • 「すること」を直すと、手本帳が覚えて、次から同じ言葉はそう読みます。
  • まちがって覚えたものは、控え・えさの欄の「手本帳の中を見る」から ✕ で外せます。

🔍 さがすSearch

  • 右上の 🔍 を押すと、さがす窓が開きます。
  • 日付（10/25明日去年の今日）を入れると、その日の予定・日記・読書・習慣が全部出ます。「この日を開く」でその日へ飛べます。
  • 言葉（歯医者頭痛）を入れると、予定・やること・1行日記・読書カード・週のメモ・繰り返しから探します。
  • 探すのは端末の中だけです。外には何も送りません。

今日とこれからToday

  • 今日の予定と「やること」が並びます。やることは ☐ を押すと済みになります。
  • 時刻が過ぎた予定は、うすくなって下へ（終わり）。
  • 明日の予定と、あさって以降（たたんであります）も見られます。
  • ✏️ を押すと、その場で直せます。
  • ↪ 繰り越し：✏️ で開いたところの「↪ 繰り越し」から、「明日・来週・来月のはじめ」へ一押しで移せます。「日と時間を選ぶ」で、好きな月日と時刻にも移せます（時刻を空にすると時刻なし）。過ぎた予定は今日を起点にします。繰り越した回数は予定の横に「↪2」のように出て、3回をこえると色が変わります。何度も運んでいるものは、本当にまだやるか考えどき。

月・週Month / Week

  • 「月｜週」で切り替え。iPhone は週、iPad は月が見やすいです（端末ごとに覚えます）。
  • 左右に指を滑らせると、月（週）が動きます。
  • 祝日は赤い枠。色の点は すること の色です。
  • 「はじまり」で月曜・日曜、「曜日」で 月火水 ／ Mon Tue を選べます。

選んだ日A day

月間や週で日付を押すと、その日の欄が開きます。

  • この日に入れる：日付を書かなくても、その日の予定になります。
  • 先月・去年の同じ日：書いてあった日だけ出ます。ためるほど楽しくなります。
  • 読書カードを使っていれば、読み始め・読了もここに出ます。

送る・日記を書くShare / Journal

「⤴︎ ○/○ を送る・日記を書く」を押すと、送り先を選ぶ画面が出ます。送り先はあなたが選びます。

送り先できること
ジャーナルその場で日記を書き足せます。写真もジャーナルで。日付を長押しすると、カレンダーやリマインダーにも入れられます
LINE・メモ・フリーボードなどその日の予定を、そのまま渡せます
送った先は、ヤドカリのおうちの外です。そこから先のことは、ヤドカリには見えません。

暗号工房Cipher

見られたくないことを、暗号にしてから手帳に書けます。入力欄のすぐ下の小さなボタン「🔐 暗号工房」（いちばん上の 🔐 からも）で、別のページの暗号工房へ飛びます。

  • 書くとき：暗号工房で暗号をえらんで文を書く →「コピーして手帳へ戻る」→ 入力欄や1行日記に貼る。
  • 読むとき：手帳の暗号文をコピー → 🔐 →「元に戻す」に切り替えて貼る → 同じ暗号と鍵をえらぶと読めます。
  • シーザー・ヴィジュネル・エニグマ・プレイフェア・モールス・点字（ひらがなもOK）・ヒエログリフ・楔形文字など16種類。それぞれ「安全度」が出ます。
本当に見られたくないことは AES を選んでください。ほかは遊びの暗号で、解かれることがあります。鍵（パスワード）はどこにもしまいません。忘れると、誰にも元に戻せません。

暗号工房も外にはつながりません。計算は全部この端末の中です。ヒエログリフ・楔形文字は、端末にその字体がないと □ に見えることがあります。

QR工房QR code

URL（ユーアールエル）や短い言葉を、QRにできます。入力欄のすぐ下の小さなボタン「QR工房」で、別のページへ飛びます。

  • 作る：「URL」か「ことば」をえらんで書く →「QRを作る」。大きさ・余白・汚れへの強さを変えると、その場で描き直します。
  • 保存する：「画像で保存」で、タイトルつきの画像になります。iPhone・iPad では送り先をえらぶ板が開くので、「画像を保存」で写真に入ります。大きく印刷するなら「SVGで保存」か「印刷」。
  • 1台だけで読む：保存した画像を写真アプリで開いて、QRのところを長押しすると、開くメニューが出ます。
  • 入れられるのは250バイトまで（日本語でだいたい80文字）。長いほどQRが細かくなって、読みにくくなります。
QRは、読めば誰でも中身が見えます。見られたくないことは、先に暗号工房で暗号にしてからQRにしてください。

QR工房も外にはつながりません。作ったQRの一覧（20件まで）は、この端末の中だけにしまいます。控え（えさ）には入りません。

リフィル工房Refill

いまはお休み中です。思ったとおりに印刷できるようになるまで、手帳の入口のボタンは灰色にして押せないようにしています。
まだ試作中です。iPhone・iPad から印刷すると、プリンターの余白に合わせて全体が少し縮むことがあります。はじめは1枚だけ普通紙で印刷して、カードの大きさを定規で測ってください（大きさはリフィル工房のサイズのボタンに出ています）。小さかったときは、PDFにしてパソコンから倍率100%で印刷すると、合うことがあります。

白い月間・週間のリフィルを、システム手帳のサイズに合わせてA4の紙に並べて印刷できます（PDFにもできます）。入力欄のすぐ下の小さなボタン「🖨 リフィル工房」で、別のページへ飛びます。予定は入りません。

  • 種類：月間（シンプル／マス）と、週間（1日1段＝1日を横長の段にして、その日の予定を何行か書ける／バーチカル＝細いマス／リスト＝3列）。1日1段は、横長のカードでは左に4日・右に3日とメモの2列になります。
  • サイズ：Micro5（縦・横）、M6（縦・横）、バイブル、A4。下に紙の見本が出ます。
  • 月間は、はじまりの月と何か月分（12か月まで）を選びます。紙が足りないぶんは自動で増えます。祝日は赤で出ます。
  • 週間は、日付を「入れない」なら白いまま何枚分かを選びます。「入れる」なら、はじまりの日とおわりの日を選ぶと、その間の週が1週ずつ日付入りで出ます（週のはじまりの曜日にそろえます。60週まで）。祝日は赤。
  • 週のはじまり（月曜・日曜）と曜日の言葉は、はじめは手帳の設定に合わせてあります。
  • 両面にすると、月間や日付入りの週間は、カード1枚の表と裏が続きの月（週）になります。プリンターの「短辺とじ／長辺とじ」はページに出る案内に合わせてください。A4は片面だけです。
  • 印刷するときは、用紙A4・倍率100%で。iPhone・iPad で PDF にしたいときは、印刷の画面で共有のボタンを押して「ファイルに保存」。
  • 両面のとき：リフィル工房の「両面」は、表と裏の並べ方を決めるだけです。プリンターを両面にするのは、印刷の画面の「両面」をオンにして、とじ方（短辺・長辺）を選びます。印刷の画面に「両面」が出ないプリンターなら、「表だけ印刷」→ 紙を裏返して入れ直す →「裏だけ印刷」で、手で両面にできます。
  • ホーム画面のアイコンから開いたヤドカリでは印刷できません（iPhone・iPad の決まりで、印刷の画面が出ません）。印刷ボタンを押すと案内が出るので、「リンクをコピー」して Safari で開いてください。ホーム画面のヤドカリと Safari は保存場所が別なので、サイズなどはそこでもう一度選びます。

リフィル工房も外にはつながりません。覚えておくのはサイズなどの設定だけで、予定の中身は使いません。元は「手帳リフィル A4印刷ツール v7」の月間・週間の部分です。

数えるCount

  • 今月の予定・出勤（うち急な出勤）・休みの数がタイルに出ます。
  • 「＋ 数える項目」で、自分の言葉を数えるタイルを足せます（例：通院・ジム・釣り）。
  • 今月使った絵文字も、数が出ます（🏥3 ☕6 のように）。
  • タイルや絵文字を押すと、その月にそれが入っている日が、月のカレンダーで青緑の枠で光ります。上に日付の一覧（同じ日に2つなら「×2」）も出ます。もう一度押すか「✕ 消す」で元に戻ります（週の表示だった人は週に戻ります）。光らせたまま月を移ると、その月のぶんで光り直します。
  • 「数える項目」は、予定の「何・場所・備考・すること」から探します。入れたときの元の文は見ないので、あとで直して消した言葉は数えません。

🗓️ 月のふりかえりReview

  • その月の予定・出勤・休み、すること の内訳、天気と気分、習慣、読み終えた本を、コードが自動でまとめます。
  • 1行日記から「よかったこと」を ★ で3つまで選べます。「この月をひとことで」も書けます。
  • 移しかえ：終わっていない「やること」を、1つずつ「来月へ・済んだ・やめる」で決めます。「来月へ」も繰り越しの回数に入ります。
  • 月の初め（1〜7日）は、先月のふりかえりから開きます。‹ › で月を動かせます。「⤴︎ ふりかえりを送る」でジャーナルにも残せます。

すること（種類）Tags

  • 出勤・休み・外出・買い物・通院 などの種類で色分けします。
  • 「🏷️ すること を足す・隠す」で、自分の種類を足せます（例：釣り）。その言葉が文にあれば、自動でその種類になります。
  • 自分で足した種類には色を選べます（例：「有休」を黄色にして、休みと分ける）。足したときに色の板が開きます。あとから変えるときは、種類の名前を押します。選んだ色は、月表示・週表示・色のしるし・月のふりかえりに出ます。
  • 出勤・休み・その他 は動かせません（日数を数えるため）。

部品Modules

「🧩 部品を足す・外す」から、使いたいものだけ足せます。足していない部品は読み込まないので、ヤドカリは軽いままです。外しても中身は消えません。部品は1つずつ別のブロックで、それぞれ少しずつ違う色です。色は「🎨 色」で部品ごとに変えられます。

  • 📚 読書カード：1冊1枚。★はその場で押せます。何日で読んだか、1日何ページかも数えます。
  • ✅ ハビットトラッカー：習慣ごとに、日付のマスを押してチェック。続いた日数を数えます。
  • 📝 週のメモ：週ごとに、自由に書ける欄です。
  • 🔁 繰り返しの予定：毎日・毎週（曜日）・毎月（日にち／第○曜日）・毎年。1回決めれば、月間・週・今日に 🔁 つきで毎回出ます。ある日だけ休む時は「この日だけ外す」。
  • 🏫 時間割：小学生から大学生まで向けの、曜日×何時間目の表です。マスを押して、科目・教室・先生・メモを書きます。一度書いた科目は丸いボタンで並ぶので、次からは押すだけ。科目ごとに色と持ち物を決めると、選んだ日のカードに「その日の時間割」と「持ち物」が出ます。「📝 この科目のやることを入れる」で、次のその科目の日の宿題が いつもの入力欄に入ります（読み取るまでは入りません）。「⚙︎ 表の形」で、曜日（月〜土）・何時間目まで（4〜8）・昼休み・時刻を決められます。
  • ✏️ 1行日記・気分・天気：その日の天気マークと気分マークを選んで、1行だけ書けます。天気は予報ではなく、自分で選ぶ記録です。月間・週のマスの隅にも出ます。天気・気分のマークは、部品の板の「＋」で自分の絵文字をそれぞれ6つまで足せます。

ほかの部品も、順番に足していきます。

カレンダーへの接続Calendar

  • 初めは「許可しない」です。許可すると、日付のある予定に 📅 が出ます。
  • 📅 を押した予定だけ、iPhone・iPad のカレンダーに「追加」できます。まとめて出すこともできます。
  • Safari で開いてください。ほかのブラウザでは渡せないことがあります。

控え・えさBackup

  • 「控えを書き出す」で、中身を1つのファイルにします。押した時だけです。
  • 別の端末で「控え・えさを読み込む」と、今ある中身に足し合わせます（消えません）。iPhone から iPad へ、AirDrop で運べます。
  • 別の端末で直した予定（「希望」を「OFF」に直した、など）は、読み込むときに「この端末 → ファイル」の一覧を出して、置きかえるか聞きます。OK なら全部ファイルのほうに、キャンセルならこの端末のまま。1件ずつは選べないので、この端末のほうが新しい予定が混ざっていたら、キャンセルしてから手で直してください。
  • カレンダーに入れた印・済んだの印は、この端末のものが残ります。消した予定は渡りません（片方で消しても、もう片方には残ります）。
  • 予定・手本帳・自分の種類・部品の中身・好み（週のはじまり・色など）が入ります。

ローカルくん（AI）Local AI

  • 使わなくても全部動きます。使いたい人だけ、席を選んで読み込みます（最初の1回だけ通信します）。
  • 📱💻 は iPhone でも動く席、💻 は iPad・パソコン向けです。iPhone で 💻 を選ぶと止まることがあります。
  • 日付や数字は見張りがついているので、AIがまちがえても大丈夫です。名前もつけられます。

ホーム画面に置くHome screen

  • Safari の共有ボタン →「ホーム画面に追加」。アイコンから開けば、アプリのように使えます。
  • 新しい版が出ると、上に「新しい版があります」と出ます。押すと新しくなります（中身は消えません）。
  • Safari とホーム画面のアイコンでは、中身の棚が別になることがあります。引っ越しは控えで。

こまったときHelp

読み取りがまちがう

確認カードで直してから入れてください。手本帳が覚えます。

予定が見当たらない

別のブラウザや、ホーム画面のアイコンで開いていませんか？ 棚が別です。

カレンダーに入らない

Safari で開いて、「カレンダーへの接続」を「許可する」にしてから 📅 を押してください。

全部やり直したい

控え・えさの欄の奥に「全部消す」があります。元には戻せないので、先に控えを。
